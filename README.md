## 📖 Giới thiệu / Overview

Repository này chứa tài liệu, bài tập và dự án cho môn học **Trí Tuệ Nhân Tạo**.

This repository contains lectures, assignments, and projects for the **Artificial Intelligence** subject. It covers the foundational concepts, algorithms, and practical applications of AI — from classical search and logic to modern machine learning and neural networks.

---

## 🎯 Mục tiêu môn học / Course Objectives

By the end of this course, students will be able to:

- Understand the core concepts and history of Artificial Intelligence.
- Apply search algorithms (BFS, DFS, A\*, heuristic search) to solve problems.
- Model knowledge using logic and reasoning systems.
- Understand and implement machine learning algorithms.
- Build and train basic neural networks.
- Apply AI techniques to real-world problems.

---

## 📚 Nội dung môn học / Course Topics

| # | Chủ đề / Topic | Mô tả / Description |
|---|----------------|---------------------|
| 1 | **Introduction to AI** | History, definitions, and branches of AI |
| 2 | **Search Algorithms** | Uninformed search (BFS, DFS), Informed search (A\*, Greedy) |
| 3 | **Adversarial Search** | Minimax algorithm, Alpha-Beta pruning, Game playing |
| 4 | **Knowledge Representation** | Propositional logic, First-order logic, Inference |
| 5 | **Planning** | STRIPS, PDDL, classical and heuristic planning |
| 6 | **Uncertainty & Probability** | Bayesian networks, probabilistic inference |
| 7 | **Machine Learning** | Supervised, unsupervised, and reinforcement learning |
| 8 | **Neural Networks** | Perceptron, MLP, backpropagation |
| 9 | **Deep Learning** | CNNs, RNNs, Transformers |
| 10 | **Natural Language Processing** | Tokenization, embeddings, language models |
| 11 | **Computer Vision** | Image classification, object detection |
| 12 | **AI Ethics** | Bias, fairness, explainability, societal impact |
